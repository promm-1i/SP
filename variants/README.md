# LE 디자인 시안 5종

`python C:/web-project/SP/make_variants.py` → `C:/web-project/LE-v1` ~ `LE-v5` 생성 (매번 새로 만듦. 시안 폴더를 직접 고치지 말고 여기 `vN/` 을 고친 뒤 다시 돌린다).
문구·사진·페이지 구성은 SP/LE 와 동일하고 배치·형태·톤만 다르다.

| 시안 | 컨셉 | 메인 히어로 | 특징 |
|---|---|---|---|
| v1 | Split 라이트 | 좌 텍스트 / 우 제품 누끼, 연회색→흰 그라데이션 | 알약 버튼, 20px 둥근 카드, 제품 지그재그, 이런분께 2×2, 둥근 CTA 카드, 둥근 상단 푸터 |
| v2 | 에디토리얼 다크 | 풀블리드 영상, 중앙 정렬, 하단 스탯 스트립 | 전체 다크 네이비, 섹션 번호 01~07, 하이라인 구분, 와이드 이미지 밴드, 스티키 스택 유지, 다크 지도 |
| v3 | 벤토 그리드 | 4열 벤토(영상 카드 + 정면 누끼 카드 + 스탯 3 + 상담 카드) | 연회색 바탕 + 흰 카드 24px, 떠 있는 알약 헤더, 제품 2×2, 이런분께 4열, 카드형 푸터 |
| v4 | 쇼룸 | 블랙, 정면 누끼 대형 + 좌우 스펙 열 | 얇은 타이포(300), 풀와이드 이미지 밴드·패널, 괘선 격자, 세로 3:4 카드, 히어로 위 투명 헤더 |
| v5 | 매거진 스티키 | 크림 바탕, 좌 텍스트+스펙 표 / 우 세로 네이비 패널 | 좌측 고정 제목 + 우측 스크롤 콘텐츠 2단, 섹션 인덱스 01~06, 얇은 괘선, 모노 대문자 내비 |

각 `vN/`:
- `theme.css` — site.css 뒤에 링크되는 오버라이드(토큰·헤더·섹션·서브페이지)
- `home.html` — 메인 본문(`<!-- HERO -->` ~ CTA). SP 문구로 써도 make_le 치환표로 LE 로 바뀐다
- `patch.py` — 서브페이지 HTML 치환(헤더 클래스, 히어로 구조 등). 없어도 됨

캡처 검증: `python variants/shot.py <폴더> <태그> [페이지] --w=1440|390 --full` (Playwright, channel=chrome)
